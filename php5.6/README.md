# Legacy: PHP 5.6 (unmaintained)

PHP 5.6 reached end of life in December 2018 and gets no security fixes.
This directory (and `../php5.6-apache-php`) is kept only as a reference for the old
`yousan/php5.6-apache` image. It is not used by `docker-compose.yml`, is not tested,
and its Dockerfile no longer builds.

The default DAMP image is now [`php8.4/apache`](../php8.4/apache).
